How to use the Browser Lab
This is an MPLPB-style web front end, not the complete Ghidra Java desktop program. The training challenges and simple x86 decoder run entirely offline in JavaScript.
  1. Pick a mission from the left.
  2. Inspect the disassembly, pseudocode, strings, or hex bytes.
  3. Enter the answer, or edit the relevant byte, and verify your solution.
  4. Upload your own executable to inspect bytes and strings. Supported machine instructions appear in the disassembler; unsupported ones appear as db.
  5. For real Ghidra decompilation, run python3 launch.py --ghidra-home /path/to/ghidra, then open a supported executable and press Analyze with real Ghidra.
Never analyze suspicious executables on a sensitive machine. Even static analysis of malformed binaries may expose tool vulnerabilities.
